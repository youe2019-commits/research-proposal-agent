# 범용 연구 지원 에이전트 작업공간

연구문제 추천, 연구설계, 계획서·보고서 작성과 문헌 탐색을 지원하는 작업공간입니다. 두 전문 역할과 여러 연구 프로젝트를 분리해 관리하며, 실행 규칙은 `AGENTS.md`와 Markdown 서식에 있습니다. 학교급·교과·디지털 수업에 역할을 제한하지 않고 사용자의 연구 분야·대상·목적에 맞춥니다.

```text
research-proposal-agent/
├─ AGENTS.md
├─ README.md
├─ agents/
│  ├─ research-design/
│  │  ├─ AGENTS.md
│  │  ├─ README.md
│  │  ├─ templates/
│  │  └─ references/
│  └─ literature-search/
│     └─ AGENTS.md
└─ projects/
   ├─ README.md
   └─ _template/
```

## 에이전트

| 폴더 | 역할 |
| --- | --- |
| `agents/research-design/` | 좋은 연구보고서 작성을 위한 연구문제 추천, 사용자 선택 후 연구설계·연구계획서 Markdown/DOCX·논리와 근거 점검 |
| `agents/literature-search/` | 연구보고서의 근거 공백을 분석하고 핵심 문헌의 서지정보와 공개 원문 PDF를 검증·저장 |

루트 `AGENTS.md`는 사용자 요청에 맞는 전문 에이전트 지침을 선택하는 라우터입니다. 실제 역할 규칙은 각 에이전트 폴더의 `AGENTS.md`에서 독립적으로 관리합니다.

현행 사용법과 변경 비교는 `agents/research-design/README.md`에 있습니다. 연구 산출물 경로 `outputs/research-proposal/`은 두 에이전트가 함께 사용합니다.

## 프로젝트

연구별 자료는 `projects/<project-name>/` 아래에 둡니다. 새 연구 아이디어를 제시하면 에이전트가 핵심 문제를 요약한 이름을 자동으로 정하고 `projects/_template/`의 구조를 복사해 바로 시작합니다. 프로젝트 이름이나 폴더 생성 허락을 별도로 묻지 않습니다. 사용자가 이름이나 경로를 지정하면 그 지정을 우선합니다.

```text
projects/<project-name>/
├─ inputs/user-provided/
├─ outputs/
│  ├─ research-proposal/
│  │  ├─ recommendations/
│  │  ├─ drafts/
│  │  ├─ final/
│  │  ├─ reviews/
│  │  └─ handoff/
│  └─ literature/
└─ literature/
   ├─ pdfs/
   └─ quarantine/
```

프로젝트명과 파일명에는 학생·교사·학교·연구참여자·기관을 식별할 수 있는 정보를 넣지 않습니다.

## 기본값과 범용 동작

사용자 메시지와 해당 연구의 지정 입력을 먼저 읽습니다. 학교교육 연구에서 빠진 항목에만 학교급 **중학교**, 교과 **사회**를 적용합니다. 세부 학년은 미지정이며 기본값 확인 질문 없이 진행합니다. 입력된 항목은 유지하고 누락 항목만 보완합니다. 학년별 단원·성취기준, 기간·인원·기기 등은 확인된 범위와 가정을 구분합니다.

대학·성인교육·수업 외 활동·다른 분야의 연구 맥락이 제공되면 중학교 사회 기본값을 적용하지 않습니다. 연구 목적에 맞게 관찰·면담·설문·사례·자료 분석이나 수업·활동 개입을 선택합니다. 디지털 도구와 사전·사후 평가는 해당 연구에 필요할 때만 사용합니다.

다음은 입력에 따른 처리 원칙의 예시이며 실제 연구를 실행해 얻은 결과가 아닙니다.

| 입력 | 적용할 맥락과 설계 원칙 |
| --- | --- |
| 학교급·교과 없이 수업 문제만 제시 | 중학교 사회, 세부 학년 미지정; 가정 표시 |
| 수학 수업 문제만 제시 | 중학교 수학; 입력된 교과 유지 |
| 초등학교 4학년 과학 연구 | 초등학교 4학년 과학; 해당 학습 수준에 맞춤 |
| 고등학교 영어 토론, 기기 사용 없음 | 고등학교 영어, 세부 학년 미지정; 비디지털 활동 설계 |
| 성인교육 참여 경험 연구 | 성인교육 맥락; 질문에 맞는 면담·설문 등 검토 |
| 조직의 의사결정 과정 사례연구 | 조직·참여자·사례 맥락; 학교급·교과·차시를 넣지 않음 |

공통 품질 원칙은 연구의 질문·방법·자료·분석·해석 연결, 실제 근거, 재현·전이 조건입니다. 보관 중인 2026년 3월 디지털 교수·학습 연구보고서 기준은 해당 제출 작업에만 적용합니다. 모든 연구에 특정 배점·디지털 도구·기간·분량·HWP/PDF 제출을 요구하지 않습니다. 사용자·제출처의 기준과 서식을 우선합니다.

## 기본 작업 순서

1. 새 아이디어를 제시하면 에이전트가 `_template` 구조를 복사해 연구 프로젝트 폴더를 자동으로 만들고 이름과 경로를 안내합니다. 같은 이름이 있으면 번호를 붙여 구분합니다.
2. 연구에 맞는 계획·활동·조사·평가 자료와 익명화한 원자료를 `inputs/user-provided/`에 둡니다.
3. 연구설계 에이전트가 연구문제를 추천합니다. 사용자가 선택하면 필요한 질문 후 연구설계·계획서 Markdown/DOCX·논리와 근거 점검을 수행합니다. 계획서 초안은 `drafts/`에, 추천·점검·인계 문서는 각각 별도 폴더에 둡니다.
4. 문헌 검색은 요청할 때만 수행합니다. 연구계획서 Markdown의 정확한 경로와 근거 공백을 입력으로 지정해 핵심 문헌을 선별합니다.
5. 문헌 검토 결과는 `<project>/outputs/literature/`, 검증한 공개 원문 PDF는 `<project>/literature/pdfs/`에 저장합니다.
6. 문헌을 보고서에 반영하는 작업은 사용자가 별도로 요청할 때 수행합니다.

연구주제를 이미 지정했다면 후보 재선택 없이 설계를 시작합니다. 문헌 탐색은 계획서가 없어도 충분한 연구주제·질문이 있으면 그 내용을 입력으로 기록해 진행할 수 있습니다. 학교교육 밖의 계획서는 수업 모델·차시 대신 해당 활동·조사·분석 절차와 일정을 사용합니다. 별도 서식이 없으면 기본 Ⅰ~Ⅳ 계획서와 Markdown·DOCX를 만들며, 출력 형식을 지정하면 그 요청을 따릅니다.

`_template`은 실제 연구 프로젝트가 아닙니다. 새 아이디어는 새 프로젝트에서 시작하며, 현재 연구의 후속 작업은 선택한 프로젝트에서 이어갑니다. 연구설계에 필요한 질문에는 가정과 미확인 사항을 표시하면서 초안 작업을 병행합니다. 계획서의 기대 변화는 실제 연구결과로 작성하지 않으며, 검색 전 근거가 필요한 곳에는 `[근거 필요]` 표시를 남깁니다.

유료벽, 로그인 제한, CAPTCHA 또는 기술적 보호조치는 우회하지 않습니다. 공개 PDF를 확보하지 못한 문헌은 공식 URL과 접근 상태만 기록합니다.
