# 디지털 교수·학습 연구 지원 에이전트

**디지털교육연구대회 디지털 교수·학습분과(수업 분과)**의 연구문제 추천, 수업 설계, 계획서·보고서 작성과 요청받은 문헌 탐색을 지원합니다. 실행 규칙은 `AGENTS.md`와 Markdown 서식에 있습니다.

범용성은 이 분과 안에서 유·초·중등(고등학교 포함)·특수교육의 다양한 교과·수업 주제·디지털 교수·학습 전략을 다룬다는 뜻입니다. 대학·성인교육·기업·조직 연구, 독립적인 SW·AI 제품 개발, 학교경영 분과로 범위를 넓히지 않습니다.

## 두 전문 역할

| 폴더 | 역할 |
| --- | --- |
| `agents/research-design/` | 연구문제 추천, 디지털 수업·평가 설계, 계획서 요약 DOCX, 내부 품질 점검, 요청받은 상세 보고서 |
| `agents/literature-search/` | 요청받은 선행연구 탐색·서지 검증·합법적으로 접근 가능한 원문 PDF 확보 |

루트 `AGENTS.md`가 요청에 맞는 역할을 연결합니다. 문헌 탐색은 요청받은 경우에만 수행하며, 계획서 작성만으로 자동 실행하지 않습니다.

## 기본 동작

- 새 연구 아이디어가 들어오면 핵심 문제를 요약한 이름으로 프로젝트를 자동 생성하고 바로 시작합니다. 이름 확인이나 생성 허락을 묻지 않습니다.
- 학교급·교과 입력이 없으면 **중학교 사회**, 세부 학년 미지정으로 진행합니다. 입력된 항목은 유지하고 누락 항목만 기본값으로 채웁니다.
- 연구계획서 요청에는 **A4 약 2~3쪽의 간략한 연구계획서 초안(요약) DOCX 한 개**를 제공합니다.
- 요약에는 연구 목적·문제, 대상·기간, 디지털 수업 흐름, 자료 수집·분석, 기대 변화·활용을 담습니다.
- 작성 근거 설명, 배점표, 문헌 공백, 점검표, 내부 원고·인계 기록은 기본 전달하지 않습니다. 사실·가정·실제 결과의 구분과 내부 검증은 유지합니다.
- 상세 계획서, 차시별 지도안, 평가 도구, 실제 결과보고서, 문헌 검토나 다른 출력 형식은 사용자가 요청한 범위에서 제공합니다.

요약 DOCX는 연구를 구체화하기 위한 편집용 초안입니다. 대회 제출용 최종 보고서나 공식 요약서를 대신하지 않습니다.

## 입력에 따른 처리

| 입력 | 적용할 맥락 |
| --- | --- |
| 학교급·교과 없이 수업 문제 제시 | 중학교 사회(가정), 세부 학년 미지정 |
| 수학 수업 문제 | 중학교 수학 |
| 초등학교 4학년 과학 | 입력 그대로 적용 |
| 고등학교 영어 디지털 협력 수업 | 해당 학교급·교과에 맞춰 설계 |
| 특수교육에서 디지털 의사소통 지원 | 입력한 학습자·교육 영역에 맞춰 설계 |
| 디지털 활용이 불가능한 조건 | 가능한 활용 방안이나 범위 조정 검토; 출품 적합성 단정하지 않음 |
| 성인교육·조직 연구 | 지원 범위 안내; 수업 분과 연구로 자동 처리하지 않음 |

기간·차시·인원·기기·연구 동의는 학교급·교과 기본값만으로 확정하지 않습니다. 출품자의 학교급·자격, 실제 제출 조건은 제공된 요강의 확인 범위에서 별도로 점검합니다.

## 프로젝트 구조

```text
research-proposal-agent/
├─ AGENTS.md
├─ agents/
│  ├─ research-design/
│  │  ├─ AGENTS.md
│  │  ├─ README.md
│  │  ├─ templates/
│  │  └─ references/
│  └─ literature-search/AGENTS.md
└─ projects/
   ├─ _template/
   └─ <project-name>/
      ├─ inputs/user-provided/
      ├─ outputs/
      │  ├─ research-proposal/
      │  │  ├─ drafts/          # 사용자용 요약 DOCX·내부 원고
      │  │  ├─ reviews/         # 내부 점검
      │  │  ├─ handoff/         # 요청 시 문헌 인계
      │  │  ├─ recommendations/
      │  │  └─ final/           # 요청 시 실제 결과보고서
      │  └─ literature/
      └─ literature/
         ├─ pdfs/
         └─ quarantine/
```

사용자가 이름·경로를 지정하면 우선합니다. 자동 이름이 겹치면 번호를 붙이며 학생·교사·학교 식별정보를 넣지 않습니다. 후속 작업은 선택한 프로젝트에서 이어가고 기존 입력·산출물을 덮어쓰지 않습니다. 설정 수정만 요청받았을 때는 연구 프로젝트나 문서를 만들지 않습니다.

## 사용 예시

> 학생들이 갈등 문제에 대해 의견은 있지만 구체적인 근거로 설득하지 못해. 연구계획서 초안을 만들어줘.

> 초등학교 4학년 과학에서 디지털 관찰 기록을 활용할 연구문제 3개를 추천해줘.

> 이 요약 DOCX를 바탕으로 6차시 수업안과 평가 도구를 구체화해줘.

> 이 계획서에 필요한 핵심 문헌을 찾아줘. 본문 반영은 하지 마.

확인된 문헌의 본문 반영도 요청받은 경우 새 버전으로 수행합니다. 실제 수업 결과·동의·문헌을 만들어내지 않으며 문헌 PDF의 접근 제한을 우회하지 않습니다.
