# 연구 프로젝트

디지털교육연구대회 수업 분과의 연구 한 건마다 폴더를 만들어 입력, 계획서 요약 DOCX, 내부 점검, 요청받은 문헌·PDF를 관리합니다. 지원 범위와 중학교 사회 기본값은 루트 `AGENTS.md`를 따릅니다.

새 연구 아이디어가 들어오면 `_template` 구조를 복사하고 핵심 문제를 요약한 이름으로 프로젝트를 자동 생성해 바로 시작합니다. 이름 확인이나 생성 허락을 묻지 않습니다. 사용자가 지정한 이름·경로는 우선합니다.

식별정보, 운영체제에서 사용할 수 없는 문자·예약 이름을 제외하고 같은 이름이 있으면 `-02`, `-03`처럼 구분합니다. 기존 자료는 덮어쓰지 않습니다. 후속 작업은 선택한 프로젝트에서 이어가며 기존 연구의 대상이 불분명한 경우에만 확인합니다.

기본 사용자 산출물은 `outputs/research-proposal/drafts/`의 간략한 요약 DOCX 한 개입니다. 내부 원고·점검·인계 자료는 기본 전달하지 않습니다.

예시:

```text
projects/digital-collaborative-writing/
projects/ai-feedback-math-class/
```

`_template`에는 실제 연구자료를 넣지 않습니다. 서로 다른 프로젝트의 자료를 합치려면 사용자의 명시적인 요청이 필요합니다.
