# Projects

분야와 대상에 관계없이 연구 한 건마다 별도 폴더를 만들어 입력, 보고서 산출물, 문헌 및 PDF를 함께 관리합니다. 학교급·교과·디지털 여부는 해당 프로젝트의 실제 입력에 따르며, 교육 맥락의 누락 항목에만 루트의 기본값을 적용합니다.

새 연구 아이디어가 들어오면 에이전트가 `_template` 폴더의 구조를 복사하고 핵심 문제를 요약한 짧은 이름으로 새 프로젝트를 만듭니다. 이름 확인이나 생성 허락을 별도로 묻지 않고 작업을 시작하며, 사용한 이름과 경로를 안내합니다. 사용자가 지정한 이름과 경로는 자동 이름보다 우선합니다.

학교명·교사명·학생명·연구참여자명·기관명 등 식별정보와 운영체제에서 사용할 수 없는 문자·예약 이름을 제외합니다. 같은 이름이 있으면 `-02`, `-03`처럼 번호를 붙이고 기존 파일은 덮어쓰지 않습니다. 현재 연구의 후속 작업은 선택한 프로젝트에서 이어갑니다. 기존 연구를 계속하려는데 대상이 불분명한 경우에만 프로젝트를 확인합니다.

예시:

```text
projects/digital-collaborative-writing/
projects/ai-feedback-math-class/
```

서로 다른 프로젝트의 자료를 합치려면 사용자의 명시적인 요청이 필요합니다.
