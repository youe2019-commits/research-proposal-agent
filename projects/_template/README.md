# 연구 프로젝트 템플릿

이 폴더를 복사해 디지털교육연구대회 수업 분과의 새 연구 프로젝트를 만듭니다. `_template` 자체에는 실제 연구자료를 저장하지 않습니다.

```text
<project>/
├─ inputs/user-provided/
├─ outputs/research-proposal/drafts/  # 기본 요약 DOCX·내부 원고
├─ outputs/research-proposal/final/   # 요청 시 실제 결과보고서
├─ outputs/literature/               # 문헌 요청 시
├─ literature/pdfs/
└─ literature/quarantine/
```

추천·내부 점검·문헌 인계 폴더는 필요한 경우 `outputs/research-proposal/` 아래에 추가합니다. 기본 사용자 산출물은 간략한 연구계획서 요약 DOCX 한 개입니다.
