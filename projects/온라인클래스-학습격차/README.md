# 온라인 클래스의 맞춤 지원을 통한 서논술형 수행 격차 완화 연구

중학교 사회 수업을 가정하고, 학생 답안의 어려움 진단·맞춤 학습 자료·개별 수행 대시보드·교사 피드백을 연결하는 디지털 교수·학습 연구 프로젝트입니다. 최초의 학습 격차 주제를 서·논술형 수행 격차로 좁혔으며, 사용자 요청과 결과물은 이 폴더 안에서 관리합니다.
