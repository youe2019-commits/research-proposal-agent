# Acceptance test cases

Each case is evaluated for minimal clarification, question-method connection, method fit, no fabricated facts, coherent final sections, and preservation of original intent.

| ID | Study type | Input idea | Expected design behavior |
| --- | --- | --- | --- |
| T1 | Quantitative intervention | “Do weekly peer-feedback workshops improve first-year writing scores?” Access: two existing classes, one semester. | Offer quasi-experimental pre/post comparison unless assignment is feasible; no question needed; label baseline comparability and sample size as confirmation needs. |
| T2 | Survey | “What factors are associated with remote-work satisfaction among entry-level employees?” | Propose cross-sectional survey, defined constructs, association analysis; avoid causal wording; use stated assumptions. |
| T3 | Qualitative | “I want to understand why rural older adults stop using telehealth services.” | Propose qualitative interviews, purposive criteria, semi-structured protocol, thematic analysis; flag consent/privacy without inventing barriers or findings. |
| T4 | Mixed methods | “How does a school coding club affect middle-school students’ engagement, and how do students experience it?” | Give each component a distinct purpose and explicit integration point; ask only if access is unknown. |
| T5 | Ambiguous education | “Teachers seem overwhelmed by AI tools. I want to research this.” | Offer a focused default scope; ask one decisive scope question only if needed; offer survey and interview choices. |
