# 디지털 교수·학습분과 제출 전 점검표

## 연구와 수업

- [ ] 연구주제가 출품자와 같은 학교급의 실제 교과·수업 맥락에 기반한다.
- [ ] 디지털 도구 사용이 학습목표, 학생 참여·상호작용, 협력, 문해력 또는 포용성과 연결된다.
- [ ] 도구 사용법 자체가 아니라 교수·학습 개선을 연구한다.
- [ ] 문제 분석, 전략 구안, 수업 적용, 관찰·평가, 개선 과정이 일관된다.
- [ ] 연구문제마다 자료원·수집 시점·분석 방법이 있다.
- [ ] 실제 결과와 계획·가정이 구분되어 있다.

## 심사 관점

- [ ] 학교·학급 특색을 반영한 독창성과 선행 사례와의 차별점을 설명했다.
- [ ] 실제 수업 적용·분석 과정을 구체적으로 보였다.
- [ ] 효과 또는 변화 주장이 실제 수업 자료에 근거한다.
- [ ] 다른 교사·학교의 적용 조건, 자원, 유의점, 변형 가능성을 제시했다.
- [ ] 학교 현장에 주는 구체적 시사점과 한계를 썼다.

## 윤리·저작권·형식

- [ ] 출처가 확인되지 않은 인용·통계·결과가 없다.
- [ ] 타인의 자료·이미지·영상·음성·폰트 등의 출처와 이용허락을 점검했다.
- [ ] 학생 개인정보와 식별 가능한 사진·영상·산출물을 익명화하고 필요한 동의를 확인했다.
- [ ] 생성형 AI 수업 활용 시 연령, 약관, 개인정보·접근권한 조건을 확인했다.
- [ ] 타 대회·이전 입상작과의 중복 출품·자기표절 위험을 점검했다.
- [ ] 본문 20쪽, 요약서 5쪽, 참고자료 10쪽 이내인지 확인했다.
- [ ] 기명본과 블라인드본의 내용은 같고, 블라인드본에는 시도·학교·직위·이름이 없다.
