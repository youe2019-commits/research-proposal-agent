# 일반 연구설계 품질 점검

- [ ] 문제, 목적, 연구문제, 전략, 자료, 분석이 같은 수업 맥락을 다룬다.
- [ ] 각 연구문제에 자료수집 전략과 분석 방법이 연결된다.
- [ ] 인과·상관·탐색적 주장이 설계와 일치한다.
- [ ] 적용 기간, 참여자 접근성, 자원, 윤리 위험이 실행 가능하거나 가정으로 표시된다.
- [ ] 사용자의 원래 수업 문제를 보존했고, 범위 변경은 설명했다.
- [ ] 근거, 설계 제안, 가정, 근거 공백이 구분된다.
- [ ] 모든 참고문헌은 제공되었거나 확인되었으며 가짜 인용이 없다.
- [ ] 계획서의 필수 항목이 완성되었거나 해당 없음으로 표시되었다.
