# 좋은 연구보고서 작성을 위한 확인된 기준

이 문서는 사용자 제공 자료 중 디지털 교수·학습 연구보고서의 추천·설계에 필요한 기준을 정리한 공용 참고자료다. 작성 기준 자체의 개정 여부나 다른 연도·지역 안내는 확인하지 않았다. 문헌 검색 결과나 우수 연구보고서 분석이 아니다. 원자료의 기준과 배점은 보존하고 사용하는 명칭만 연구보고서 품질 관점의 용어로 바꿨다.

**자료:** 사용자 제공 연구보고서 작성 기준 자료, 2026년 3월  
**확인일:** 2026-10-09  
**원본 보관본:** 이 폴더의 `report-quality-source.pdf` (사용자 첨부 파일을 이름만 바꿔 복사했으며 내용은 동일함)  
**페이지 기준:** PDF는 54페이지이며, 아래 PDF 페이지는 파일의 1부터 시작하는 순번이다.

## 적용 범위

아래 배점·학교급 조건·권장 기간·분량·편집·제출 파일·보관 안내는 이 자료가 적용되는 디지털 교수·학습 연구보고서 제출 작업의 기준이다. 범용 연구설계의 공통 필수 요건이 아니다. 해당 제출 목적이 확인된 경우에 사용하고, 다른 연구에는 사용자·제출처의 기준을 우선한다. 별도 기준이 없으면 질문·방법·자료·분석의 일관성과 재현·전이 조건을 배점 없이 점검한다. 아래의 원자료 요약과 수치는 그대로 보존한다.

## 품질 평가와 연구설계

- PDF 13페이지 / 인쇄 9쪽: 연구목적의 독창성 20, 연구방법의 타당성 10, 연구 활동의 체계성 15, 연구 내용의 효과성 15, 일반화 가능성 20, 학교 현장에 대한 시사성 20, 총 100점.
- 같은 쪽: 동점이면 일반화 가능성·시사성, 목적·방법, 내용, 결과 순으로 비교한다. 따라서 다른 교사의 적용 가능성과 현장 시사점을 추천·설계에서 크게 고려하는 것은 이 에이전트의 설계상 판단이다.
- PDF 12페이지 / 인쇄 8쪽: 디지털 기반 수업 개선, 참여·공유·협력, 하이브리드 수업, 디지털 문해력, 다양한 학습자 포용 등이 연구 내용에 해당한다. 연구자와 같은 학교급의 주제여야 하며 학기 단위 이상 적용은 권장 사항이다.
- PDF 14페이지 / 인쇄 10쪽: 환경 분석, 주제 선정, 전략 구안, 적용·관찰, 평가, 보고서 완성의 절차를 예시로 제시한다. 주제와 연구자의 의도에 따라 변경할 수 있다.
- PDF 13페이지의 효과성 기준은 실제 수업 적용에서 효과를 측정하고 구체적인 분석 결과를 제시하는지 평가한다. 연구계획 단계의 기대 변화만으로 실제 효과를 충족했다고 판단하지 않는다.

## 계획서와 제출 보고서

- PDF 41페이지 / 인쇄 37쪽: 최종 보고서 구성은 Ⅰ 연구 배경 및 목적, Ⅱ 연구 방법, Ⅲ 연구 내용, Ⅳ 연구 결과, Ⅴ 결론 및 일반화, 참고문헌이다.
- 사용자가 요청한 네 장 계획서와 최종 보고서 구성은 구분한다. 계획서는 Ⅳ 안에 결과 확인 계획과 일반화 조건을 두고, 최종 보고서 요청 시 Ⅴ를 확장한다.
- PDF 15페이지 / 인쇄 11쪽: 본문 20쪽 이내(표지·목차·참고문헌 제외), 요약서 5쪽 이내, 참고자료 10쪽 이내. 최종 제출 파일은 HWP·PDF 및 각각의 블라인드본이다. DOCX는 사용자 요청에 따른 편집용 초안이다.
- PDF 10·40·41페이지 / 인쇄 6·36·37쪽: 한글워드프로세서 기준, A4, 흑백 양면, 바탕체 사용. 연구 제목 20pt, 대제목 15pt, 중·소제목 12~14pt, 참고문헌 14pt. 본문 글씨 크기·자간은 자유이며 다단 설정은 금지한다.
- 같은 서식: 여백 위·아래 10mm, 머리말·꼬리말 10mm, 좌·우 20mm. DOCX와 HWP의 레이아웃이 같다고 가정하지 않고 제출 변환 시 다시 확인한다.

## 해당 연구에서 확인할 조건

- PDF 6페이지 / 인쇄 2쪽: 쉬운 연구 제목, 표절·저작권·중복 제출, 생성형 AI 서비스 약관상 의무 등을 안내한다.
- PDF 9페이지 / 인쇄 5쪽: 디지털 도구 활용과 교수·학습 개선의 관련성, 실제 원자료 제출 가능성 등을 확인한다. 원자료는 평가 결과 발표일까지, 우수 연구보고서로 선정된 경우 선정 후 최소 1년 이상 보관하도록 한다.
- PDF 12페이지 / 인쇄 8쪽: 분량 초과·블라인드 미처리·컬러 인쇄·지정 글꼴 미준수는 사전 평가 감점 요인이다.
- PDF 15페이지 / 인쇄 11쪽: 참고자료는 실제 수업 적용 과정에서 산출된 자료를 포함하며 평가만을 위한 별도 자료 제작은 지양한다.

이 요약만으로 최신 적용 대상·일정·지역 안내·서비스 약관이 확인됐다고 쓰지 않는다. 제출 점검 요청이 오면 해당 자료의 적용 범위와 확인일을 새로 기록한다.
