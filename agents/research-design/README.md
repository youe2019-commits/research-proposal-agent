# 디지털 교수·학습 연구설계 에이전트 사용 안내

이 폴더의 `AGENTS.md`는 디지털교육연구대회 디지털 교수·학습분과(수업 분과)의 연구 추천·설계·계획서·보고서 작성 지침입니다.

## 지원 범위와 기본값

유·초·중등(고등학교 포함)·특수교육의 다양한 교과·학습자·디지털 수업 전략에 대응합니다. 디지털 활용을 학생 참여·공유·협력·피드백·학습 지원과 연결해 수업을 적용하고 변화를 확인할 계획을 세웁니다. 특정 도구나 생성형 AI에 고정하지 않습니다.

입력을 우선하며 누락 항목만 중학교·사회로 채웁니다. 세부 학년 숫자는 기본값에 포함하지 않고 기본값 확인 질문 없이 진행합니다. 대학·성인·조직 연구, 독립적인 제품 개발, 학교경영 분과 작업은 지원 범위에 포함하지 않습니다.

## 기본 결과물

계획서 요청의 기본 결과는 **연구계획서 초안(요약) DOCX 한 개**입니다. A4 약 2~3쪽을 목표로 아래 내용을 간략히 담습니다.

1. 수업 문제·목적·연구문제
2. 대상·기간·자료 수집·분석
3. 디지털 활용과 단계별 수업·연구 흐름
4. 기대 변화·예상 산출물·다른 수업에서의 활용

작성 근거 설명·배점표·문헌 공백·점검표·내부 Markdown은 기본 제공하지 않습니다. 내부 검증과 필요한 출처 표시는 유지합니다. 요약은 후속 구체화용 초안이며 대회 제출용 최종 보고서나 공식 요약서가 아닙니다.

## 요청별 처리

| 요청 | 처리 |
| --- | --- |
| 새 아이디어로 계획서 작성 | 프로젝트 이름 자동 생성 후 요약 DOCX 작성 |
| 연구문제 추천 | 기본 3개 후보를 짧게 제시 |
| 이미 정한 주제로 설계 | 재선택 없이 설계·요약 DOCX 작성 |
| 상세 계획서·수업안·평가 도구 | 요청한 범위에서 구체화 |
| 지정 서식·출력 형식 | 지정 내용 우선 |
| 실제 결과보고서 | 실제 자료로 분석·결론·일반화 작성 |
| 근거 설명·점검표 | 요청받은 경우에만 제공 |
| 문헌 탐색·검증·PDF | 요청받은 경우 문헌 역할로 수행 |
| 확인된 문헌의 본문 반영 | 요청한 범위에서 새 버전에 반영 |

## 저장과 역할 연결

요약 DOCX는 `<project>/outputs/research-proposal/drafts/`에 저장합니다. 내부 원고를 사용하면 같은 내용의 Markdown을 두고, 내부 점검은 `reviews/`, 문헌 인계는 요청 시 `handoff/`에 둡니다. 사용자에게는 요약 DOCX 링크와 짧은 안내로 완료를 보고합니다.

문헌 요청에는 정확한 원고 또는 DOCX 경로·버전과 내부 근거 공백을 전달합니다. 문헌 결과·PDF는 같은 프로젝트의 문헌 경로에 저장하고 기본 계획서에 자동 추가하지 않습니다. 자동으로 별도 채팅·하위 에이전트를 만들지 않습니다.

기존 자료를 덮어쓰지 않으며 새 아이디어와 후속 수정의 프로젝트를 구분합니다. 설정 수정만 요청받았을 때는 공용 지침·서식만 수정합니다.

## 사용 예시

> 학생들의 근거 있는 설득을 돕는 디지털 토론 수업으로 계획서 초안을 만들어줘.

> 초등학교 4학년 과학의 디지털 관찰 기록 수업으로 결정했어. 요약 DOCX를 만들어줘.

> 이 요약을 바탕으로 4주 수업 흐름과 평가지를 자세히 만들어줘.

> [요약 DOCX 경로]에 필요한 문헌을 찾아줘. 원본 계획서는 수정하지 마.
