# 범용 연구설계 에이전트 사용 안내

이 폴더의 `AGENTS.md`는 연구문제 추천, 연구설계, 연구계획서·보고서 작성과 논리·근거 점검의 실행 지침이다. 특정 학교급·교과·디지털 수업에 역할을 제한하지 않고 사용자 입력과 연구 목적에 맞춰 설계한다. 두 전문 역할 구조와 `outputs/research-proposal/` 경로를 유지한다.

## 기본값과 지원 범위

학교교육 연구에서 학교급·교과가 빠졌으면 루트 지침에 따라 중학교·사회를 적용한다. 세부 학년 숫자는 기본값에 없으며 확인 질문 없이 가정을 표시하고 진행한다. 입력이 수학이면 중학교 수학으로, 초등학교 4학년 과학이면 그 맥락 그대로 설계한다. 대학·성인교육·수업 외 활동·다른 분야의 연구에는 중학교 사회 기본값을 넣지 않는다.

디지털 도구는 활용하는 연구에서만 역할과 접근 조건을 설명한다. 비디지털 수업, 관찰·면담·설문·사례·자료 분석도 질문에 맞춰 선택한다. 모든 연구를 수업 개입이나 사전·사후 평가로 바꾸지 않는다. 관련 없는 학교급·교과·차시 항목은 생략하거나 해당 없음으로 표시한다.

## 작업과 산출물

| 요청 | 처리 |
| --- | --- |
| 연구문제 추천 | 기본 3개 후보를 연구문제·방법과 절차·실행 모델·기대 또는 확인할 결과로 제시 |
| 주제 지정 후 설계·계획서 | 재선택 없이 설계하고 기본 Markdown·DOCX와 논리·근거 점검 작성 |
| 수업 연구 | 수업 모델·차시·학생 활동·교사 지원·학습 평가 구체화 |
| 조사·사례·다른 분야 연구 | 대상·연구자 역할, 조사·분석 절차, 수집 일정과 해석 기준으로 조정 |
| 지정 서식·출력 형식 | 기본 목차·편집·출력보다 사용자·제출처 지정 우선 |
| 실제 결과보고서 | 지정된 실제 자료를 분석하고 결과·한계·결론을 작성 |
| 문헌 탐색·검증 | 요청할 때만 문헌 역할로 전환; 계획서가 있으면 정확한 경로·버전 전달 |
| 확인된 문헌의 본문 반영 | 요청한 범위에서 새 버전으로 반영하고 점검·출력 갱신 |

공통 품질 요소는 목적의 명확성, 방법의 타당성, 활동의 체계성, 근거와 결과의 적절성, 재현·전이 가능성, 시사성이다. 별도 기준이 없으면 배점 없이 점검한다. `references/report-quality-criteria.md`의 2026년 3월 디지털 연구보고서 배점·학교급·권장 기간·분량·제출·보관 조건은 해당 제출 목적에만 적용하며 원래 기준과 배점을 보존한다.

## 두 역할의 연결

```text
사용자 → 루트 AGENTS.md
  → research-design: 추천 또는 지정 주제 → 설계 → 계획서·점검
  → 사용자가 문헌 작업 요청
  → literature-search: 정확한 계획서 경로 또는 사용자 연구질문 → 검색·검증·PDF·근거 지도
  → 사용자가 본문 반영 요청
  → research-design: 확인된 근거를 새 버전으로 반영 → 재점검·출력 갱신
```

자동으로 별도 채팅이나 하위 에이전트를 만들지 않는다. 추천·점검·인계 문서는 `drafts/` 바깥에 두고, 문헌 작업에서 정확한 입력 경로를 지정해 다른 주제의 이전 보고서가 선택되지 않도록 한다. 실행 전 계획과 실제 연구결과, 원문·초록·서지 확인 수준을 구분한다.

## 사용 예시

> 학생들이 근거 없이 주장하는 수업 문제로 연구계획 초안을 만들어줘.

> 초등학교 4학년 과학에서 관찰 기록을 개선할 연구문제 3개를 추천해줘. 기기를 사용하지 않을 거야.

> 고등학교 영어 토론 수업으로 결정했어. 연구설계, 계획서 Markdown·DOCX, 논리와 근거 점검까지 해줘. 문헌 검색은 아직 하지 마.

> 성인교육 참여 경험을 살펴보는 면담 연구를 설계해줘. 내가 지정한 계획서 서식을 사용해줘.

> 조직의 의사결정 과정 사례연구에 필요한 핵심 문헌을 찾아줘. 학교교육 연구가 아니야.

> [계획서 Markdown 경로]의 근거 공백을 검색하고 공개 PDF를 확보해줘. 본문 반영은 하지 마.

새 연구 아이디어는 루트 규칙에 따라 이름과 프로젝트를 자동 생성하고 바로 시작한다. 후속 작업은 선택한 프로젝트에서 이어간다. 설정 수정만 요청받으면 연구 프로젝트나 연구 산출물을 만들지 않는다. 원자료와 기존 연구 산출물은 덮어쓰지 않는다.
